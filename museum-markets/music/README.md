# 自备配乐

把一首你**有权使用**的音乐（mp3 / m4a / wav / flac）放进本目录，例如 `music/we-never-remix.mp3`，
再运行 `./build.sh --mix`（或完整 `./build.sh`），成片就会用它替代合成配乐：

- 取前 78 秒（`MUSIC_START=12 ./build.sh --mix` 从第 12 秒开始截取）
- 响度统一后垫在音效下面；1.2 s 起淡入，76–78 s 跟随收黑淡出
- 每个年份块浮现时压低 3 dB 一拍，羽管键琴报时音仍叠在上面
- 音效（叮/沙/吱…咔/沙沙/铿/嗒）照旧

本目录里的音频文件不会被提交（见 .gitignore）——商用歌曲请自行确认授权。
目录为空时自动使用 `bgm.wav`（tools/score.py 合成）。
