## 构建

```bash
./build.sh            # 配乐(如缺) → 逐帧渲染 → 合成 out/认识交易市场.mp4
./build.sh --score    # 只重新合成 bgm.wav + sfx/
node render.mjs --stills 90,300,500   # 抽帧 → stills/
```

- `index.html` —— 全部画面。所有动画由 `window.seek(frame)` 驱动：无 CSS transition、无 `Date.now()`、
  无 `Math.random`（尘埃、颗粒、米粒等位置都由帧号/序号代入哈希函数）。顶部是可调参数。
- `render.mjs` —— Node 22 内置 WebSocket 直连 Chrome DevTools Protocol，每帧 `seek(n)` →
  `Page.captureScreenshot`，多标签页并行、按帧序管道给 ffmpeg。不录屏。
- `tools/score.py` —— numpy 合成配乐与音效（低音提琴 55+110 Hz 长音、羽管键琴泛音、S7 弦乐升调；
  叮/沙/吱…咔/沙沙/铿/嗒）。`build.sh` 里用 ffmpeg 按帧号定位并混音（音效 −8 dB、配乐 −20 dB，
  每个年份块浮现时配乐压低 3 dB 一拍）。
- `tools/fonts.py` —— 把思源宋体（Noto Serif SC）与 Playfair Display 子集化后内联进 `index.html`；
  改了画面文字后先 `./tools/fetch-fonts.sh` 再运行它。
- `tools/sheet.py` —— 把 `stills/` 拼成接触印样，方便质检。
