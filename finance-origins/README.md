## 构建

```bash
./build.sh                                   # 渲染 + 编码 + 混音 → out/金融的起源.mp4
MUSIC=/path/track.mp4 ./build.sh --mix       # 换配乐（任意音/视频文件的音轨），MUSIC_START= 截取起点，SFX_DB= 音效音量
node render.mjs --stills 100,500             # 抽帧 → stills/
```

字体、配乐合成、渲染器与 `museum-markets/` 相同；音效混音默认 −22 dB。
