## 构成

- `script.py` — 解说稿（每行 = 一条字幕 = 一段语音；`【】` 为金色关键词；`tts` 字段用同音字纠正多音字/生僻字读音）
- `tools/voice.py` — 离线 TTS（sherpa-onnx + Kokoro v1.1 中文男声），降调约 2 个半音 + 暖色 EQ + 轻混响，
  每句用 Paraformer 语音识别回读校验，生成 `timeline.json`、旁白轨与 `.srt`
- `tools/music.py` — 参考片原曲按节拍无缝延长（56 拍 / 32 拍乐句自相似度 > 0.9 处回跳，60 ms 等功率交叉淡化）
- `tools/prep.py` — `build/timeline.js` 与按需子集化的字体 `fonts.css`（Noto Serif SC + Cormorant Garamond）
- `index.html` + `src/*.js` — 画面：每帧都是时间的纯函数（无随机、无 CSS 动画），浏览器打开 `index.html?t=秒` 可预览任意时刻
- `render.mjs` — Playwright 多页并行逐帧截图
- `build.sh` — 一步出片：`./build.sh 参考片.mp4 模型目录 [fontsource目录]` → `out/博弈的符号.mp4`

年代与出处均为通俗科普口径；画面中的城市网络、K 线、价格均为示意。
