# 重新理解价格与价值 — TradingNow 知识科普片

1920×1080 · 60 fps · 4′07″ · 原曲配乐（去除铃声）+ 合成音效 + 烧录字幕（另附 `.srt`）。
视觉与《博弈的符号》同一套系统：暖黑底、顶光锥与浮尘、金色线稿、衬线排版，左上角章节滚轮、右上角出处与朱印，参考片水印原位叠加。

| 章节 | 画面（形变衔接） | 音效 |

| 终极总结 | 浪花（新手·价格）、风向（老手·供求）、冰山（高手·价值） | 三次轻柔起势，终幕低频收束 |

## 构成
- `script.py` 字幕文本；`tools/timeline.py` 按阅读速度排时，并按配乐长度分配余量
- `tools/music.py` + `tools/debell.py` 原曲去铃声、按乐句无缝延长
- `src/scenes.js` 画面与音效提示点（`buildCues`）；`tools/cues.mjs` 导出提示点；`tools/sfx.py` 合成音效并混音
- `render.mjs` 60 fps 逐帧渲染；`build.sh` 一步出片：`./build.sh 参考片.mp4 [fontsource目录]`
