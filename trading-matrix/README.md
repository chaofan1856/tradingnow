# 交易的矩阵 — TradingNow 知识科普片

3840×2160 · 60 fps · 4′36″ · BT.709 · 原曲配乐（去除铃声）· 无音效 · 烧录字幕（另附 `.srt`）。
纯黑底 + 胶片颗粒 + S 曲线对比；720 个金色光点组成的「矩阵」贯穿全片，在每一节重新排列成新的图形（透视网格 → 天平 → 不对称收益分布 → 光影矩阵 → 选美 → 买卖粒子流对撞 → 四层同心圆 → 各维度图解），转场即光点重组，没有硬切。

| 章节 | 画面 |
|---|---|
| 开场 · 片名 | 透视光点网格与扫描光带 |
| 核心一 风险与收益 | 金色天平（风险云 / 收益币堆）、本金底线、截断于 −1R 的不对称收益分布、截断亏损让利润奔跑 |
| 核心二 非理性博弈 | 36×20 光影矩阵：情绪波纹、由光编织的 K 线、山岳、价格偏离价值；凯恩斯选美 |
| 核心三 供需撮合 | 买卖粒子流对撞出即时均衡点、马歇尔剪刀、威科夫涨跌、好资产 / 垃圾资产、订单流 |
| 四个维度 | 四层几何同心圆，光束由外圈扫向核心；概率（期望曲线、1–2% 风险）、反身性环与 Sell the fact、流动性清扫、自我管理核心 |
| 片尾 | 纯黑上的白色细体金句与英文 |

## 构成
- `script.py` 字幕；`tools/timeline.py` 按阅读速度排时（长句自动折行）；`tools/music.py` + `tools/debell.py` 配乐；`tools/mix.py` 响度归一
- `src/scenes.js` 光点矩阵与各节图解；`src/main.js` 字幕（五种入场：翻转、聚合、字距收拢、光幕擦出、中心放大；关键词下划线与扫光）、页眉、章节标题飞入页眉
- `render.mjs` 逐帧渲染（DPR 2，原生 4K）；`tools/segment.sh` 渲染一段并在 ffmpeg 中加胶片颗粒、调色、x264 编码；`tools/master4k.sh` 分段渲染并无损拼接
- 一步出片：`python3 tools/timeline.py 参考片.mp4 && python3 tools/prep.py 字体包目录 && python3 tools/mix.py && tools/master4k.sh`
